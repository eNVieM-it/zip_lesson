# 🗜️ Цифрова експедиція: Таємниці стиснення даних (8 клас, § 2.2)

Інтерактивний навчальний веб-тренажер з інформатики для учнів 8-го класу за темою: **«Архіватори. Операції над архівами файлів»**.

## 🚀 Як відкрити / розгорнути на GitHub Pages:
1. Завантажте файли цього репозиторію у свій GitHub-репозиторій.
2. Перейдіть у **Settings** ➔ **Pages**.
3. У полі **Source** оберіть гілку `main` (або `master`) та папку `/ (root)`.
4. Натисніть **Save**. За кілька секунд сторінка стане доступною в мережі!

## 📦 Склад проєкту:
- `index.html` — розмітка навчальних блоків, симуляторів та сертифіката.
- `style.css` — авторська стилістика без шаблонів (Cormorant Garamond + Plus Jakarta Sans).
- `script.js` — симуляція роботи 7-Zip, контекстного меню, калькулятор коефіцієнта K та прогрес у LocalStorage.
- `images_base64.js` — автономні ресурси та ілюстрації з підручника.
- `*.png` — графічні схеми та значки з підручника.
